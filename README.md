# Black Car Luxury Limo (React + Vite + Tailwind + SSG) Updated

Production-ready, mobile-first luxury transportation website with 4 pages:
- /
- /services
- /fleet
- /contact

## Stack
- React
- Vite
- Tailwind CSS
- React Router
- Custom SEO metadata component (per-page title + description)
- react-snap (SSG pre-render)

## Run
Use npm.cmd in this Windows environment.

### Development
npm.cmd run dev

### Production build
npm.cmd run build

### SSG pre-render
npm.cmd run ssg

This will build the app and pre-render routes into static HTML snapshots in dist.

## Notes
- Mobile-first responsive layout with md/lg/xl enhancements
- Sticky navbar with animated mobile menu
- Reusable cards and CTA components
- Semantic sections and optimized local SVG imagery
